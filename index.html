How Binary Search Works

1

Start with the first and last elements of the sorted array.

2

Find the middle element of the current search range.

3

Compare the middle element with the target.

4

If the target is smaller, search the left half. Otherwise, search the right half.

5

Repeat until the target is found or the search range becomes empty.
